## Maintainers

*None yet besides the lead maintainer.* The project is looking for maintainers from relying parties (banks,
insurers), agent operators, identity-platform vendors and independent contributors, so that no single
organisation holds a majority. If you want to help, start with [CONTRIBUTING.md](CONTRIBUTING.md) and say so in an
issue.

## Areas looking for owners

- **The v0.5 move to SD-JWT VC** ([proposal](docs/proposals/0.5-sd-jwt-vc.md)): conformance vectors first, then
  the verifier, the issuer and vbot
- **Verifier implementations in other languages** (Java, Go, .NET), checked against the conformance vectors
- **Authorisation-server integrations:** PingFederate, Microsoft Entra ID and Curity, beside the Keycloak bridge
- **Transparency log monitoring:** a monitor operators can run against their own domains
- **Security review** of the specification and the verification checks
