# Security policy

Please report weaknesses in the specification privately: open the **Security** tab of this repository and choose
**Report a vulnerability**. Do not open a public issue.

Describe the attack and which section of [`docs/specification.md`](docs/specification.md) it affects. We aim to
acknowledge reports within 5 working days and to agree a disclosure date with you.

This is a draft specification, version 0.1. It has not had an independent security review.
